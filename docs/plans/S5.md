## Review Focus
- API asleep (Render cold start ~50 s) → snapshot appears within 5 s with a banner and a "Retry live" button; when live data arrives it replaces the snapshot.
- Approve clicked while offline/snapshot → button disabled with tooltip "Live API needed to record decisions" (no silent fake success).
- 0 groups in a run → friendly empty state ("No stock in the wrong place today"), not a blank table.
- `evidence` values `null` → render "—", never "null"/"NaN"; `cover_days` null (infinite) → "∞".
- Phone width (judges may open on mobile): table collapses to stacked cards under 640 px, no horizontal page scroll.
